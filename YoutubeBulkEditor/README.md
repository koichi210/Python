# YouTube 動画一括編集ツール

自分のYouTubeチャンネルの動画を一覧表示して、タイトルと公開設定（公開/限定公開/非公開）を
編集・一括変更できるローカルWebアプリ。

- 一覧表示：サムネイル・タイトル・公開設定・アップロード状態
- 個別編集：タイトル、公開設定を変更して行ごとに保存
- 一括変更：複数選択して公開設定をまとめて変更（ドラフト動画を一括で限定公開にする、など）

## 事前準備（初回のみ）

### 1. Google Cloud Console でプロジェクトを作成

1. https://console.cloud.google.com/ にアクセスし、新しいプロジェクトを作成（既存のでもOK）
2. 「APIとサービス」→「ライブラリ」から **YouTube Data API v3** を検索して有効化

### 2. OAuth同意画面の設定

1. 「APIとサービス」→「OAuth同意画面」
2. User Type は「外部」を選択（個人アカウントなら基本これでOK）
3. アプリ名・自分のメールアドレスなど必須項目を入力して保存
4. テストユーザーに **自分のGoogleアカウント（YouTubeチャンネルを持っているアカウント）** を追加
   - 公開審査は不要。テストユーザー登録のままでずっと使える

### 3. OAuthクライアントIDを作成

1. 「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuthクライアントID」
2. アプリケーションの種類は **「デスクトップアプリ」** を選択
3. 作成後にJSONをダウンロード
4. ダウンロードしたファイルを `client_secret.json` にリネームして、このフォルダ
   （`D:\GitHub\Python\YoutubeBulkEditor\`）直下に置く

⚠️ `client_secret.json` と、初回認証後に自動生成される `token.json` は
**絶対にGitHubにpushしない**（`.gitignore` 済みだけど念のため確認してね）。

### 4. 必要なパッケージをインストール

```
py -3 -m pip install -r requirements.txt
```

## 使い方

```
py -3 app.py
```

起動したら、ブラウザで http://127.0.0.1:5050 を開く。

初回だけ、ブラウザでGoogleのログイン・権限許可画面が別タブで開くので、
自分のYouTubeチャンネルのアカウントでログインして許可する
（「このアプリはGoogleで確認されていません」的な警告が出たら
「詳細」→「（アプリ名）に移動」で進める。自分専用アプリなので問題なし）。

1. 「動画一覧を取得」を押す
2. 一覧が出たら、行ごとにタイトル・公開設定を変更して「保存」
3. まとめて変えたい場合は、チェックボックスで複数選択→
   上部の「一括適用」から公開設定を選んで一括変更

## 注意点

- YouTube Data API には1日あたりの利用量上限（デフォルト10,000 units）がある。
  動画一覧の取得は動画50件ごとに約100 units消費するので、数千本規模だと
  1日で使い切る可能性がある（その場合は翌日また実行すればOK）。
- アップロード処理が完了していない動画（サムネ生成中など）は取得・変更できない場合がある。
